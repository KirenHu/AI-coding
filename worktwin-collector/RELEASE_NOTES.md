# WorkTwin Collector 1.1.8 · 私有知识自动维护优先

1.1.8 将知识库从逐条审核改为默认后台自动维护；以下功能在 PR #19 中实现，合并与发布以全套 CI 验收为前提。

- 已授权 AI 处理的来源：有原文证据、明确归因且质量可用的新知识在本地自动生效；不再要求用户先给每份文件、Codex/Claude Code 会话创建一个已确认业务项目。无法自动归属的内容限定在单份资料的会话范围。
- 同主题的无冲突追加依旧严格保留已有正文；有可靠来源时间顺序的新决定可以自动替代旧结论，并保存原文与版本历史。
- 同一文件被实际修改、旧原文证据已全部失效时，系统可以对比旧文章与新文件，再自动替代为当前版本，不再必须生成重复草稿或待确认更新。
- 升级 1.1.7 后因旧文件夹归属推断而被暂停、但全部证据仍来自单份有效授权资料的知识，自动收窄为该资料的会话范围并恢复；混合来源、过期原文和权限撤销不在自动恢复范围。
- 个人知识库可用状态不再等同于“人工核对”。由 AI 自动生效的文章在界面上明确标注 AI 身份。项目关联仍可手动纠正，但默认是可选操作而非必经流程。
- AI 自动替代不覆盖用户直接编辑的文章；跨来源推断不凭同名或同目录自动合并；来源 AI 授权、每个分身的知识访问授权、远程分享权限以及完整日志授权保持原边界。

## 仍未完成

可靠自动归属跨来源业务项目、分身的规则化自动知识分配、对大规模真实本人资料的持续质量评测、完整原始编程工具操作结果核验以及浏览器事件采集仍未交付。存在无法判断时先隔离或保留可选建议，不将其标记为已人工确认。
