# WorkTwin Collector v0.6.0 · 2026-10-08

- 新增基于证据的后台知识养护：长文、多证据、历史多次修订的知识在空闲期由企业 BYOK 模型自动提出精简与重组建议。

- 不因单纯编排建议阻止已确认知识被分身查询；用户接受后保留历史和相关证据。
- 研究 Viven、Rowboat、remio 的官方产品流程，深入核查 Rowboat `build_graph.ts`、`note_curation.ts`、`knowledge_index.ts`。
- 参照开源设计改造 Python/SQLite 后台，不引入 Ollama、Electron/Node 主服务，也没有直接复制第三方可执行源码。
- 增加 `tests/test_gardener.py` 与 [竞品源码与设计审计](docs/COMPETITOR_AUDIT.md)。

## 仍待验证

# WorkTwin Collector v0.5.0 · 2026-10-08

- 以可核对更新替代静默知识覆盖：AI 生成新增、补充、替换、冲突提案，员工确认后才真正修改。
- 「我的知识库」内新增待核对更新入口；对照旧新版、查看来源、接受/忽略。没有增加一级导航或新的复杂参数页。
- 已确认的知识在待核对期间不参与数字分身问答；被替换的旧证据保留历史但不进入模型上下文。
- 数据来源部分撤销后留下的混合知识进入人工复核状态；更新提案绑定来源哈希与目标版本。
- 提炼任务支持限次指数退避重试和脱敏错误摘要；去重范围限制到项目、类型、证据。
- 新增 v0.5 回归与 Chromium 实际交互测试。
- 兼容 v0.4 SQLite 原地升级，无需清库。

# Release notes

## v0.4.0 · Knowledge-first workflow

### 面向用户

- 由技术管理后台改为 **我的知识库 / 我的数字分身 / 信息采集** 三个唯一一级入口。
- 知识库采用项目目录、中心搜索列表和右侧文档详情／编辑，支持查看原始出处。
- 分身提供创建、编辑、删除、勾选知识、保存授权以及基于授权知识的试问功能。
- 采集按数据类型呈现；本地采集与「允许 AI 整理」是两个独立开关。

### 后端

- 无默认 LLM/Ollama 依赖。移除旧本地模型 UI/运行路径，采集只负责扫描并建立本地索引。
- 添加按文件哈希维护的 `ai_jobs` 队列；独立 `KnowledgeWorker` 按间隔消费任务，失败可重试。
- 新增 OpenAI Chat Completions 兼容的企业 BYOK 网关；模型供应商密钥仅由网关持有。
- 模型返回 JSON 后验证每个知识的原文引文；Codex/Claude 会话仅将员工发言作为个人观点提炼的输入。
- 增加多数字分身与知识多对多授权；问答仅携带已分配、有效、未归档知识。
- 取消来源授权和更新资料后，旧版证据不再被数字分身用于回答；处理期间的撤权二次复核避免失效知识复活。
- 增加真实 HTTP 网关链路和 Chromium UI 点击验收。

### 已知限制

- 当前为本地试点客户端。企业网关使用简单 Bearer Token，应部署在组织 IAM / TLS / 审计机制之后。
- 不提供签名后的 .app、多人账号与远程分身共享。
- 知识提取建立条目而非完整的跨会话自动合并；真实模型质量尚需针对员工真实工作资料评测。
