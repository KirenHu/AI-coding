# WorkTwin Collector 1.1.7 · 经确认的业务项目身份与跨来源知识

- 目录、文件路径与会话启动路径只作为线索；未经确认的普通文件、Codex 和 Claude Code 会话均按独立资料范围处理。不得凭目录名自动认定业务项目。
- 在来源资料窗口中，用户可以创建新的独立项目身份，或明确关联到已有已确认项目。同名项目不会因为名字相同而自动合并；再次确认已分配项目不会改写项目身份。
- 已明确关联且所有来源仍授权 AI 使用的跨目录/跨会话资料，可以共同参与同主题知识的更新建议。不同来源内容的变更依旧通过原有审核与证据准入，不等于无条件自动覆盖。
- 原先依据文件夹推断出的未确认项目关联在升级时改为单份资料范围，暂停仍沿用推断身份的关联知识（即使正文被手工修改），保留资料、知识正文与历史；已经人工重新指定明确项目范围的内容不受此次迁移影响，避免旧关联继续误用。
- 保留已有按资料显示的项目概览和摘要接口，新增已确认项目身份列表，用于明确关联。
- 更新集成与回归测试，使跨文件更新必须以显式确认项目为前提，检查同名项目隔离、撤销 AI 授权及历史迁移。
