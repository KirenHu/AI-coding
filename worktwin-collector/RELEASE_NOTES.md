# WorkTwin Collector 1.1.9 · 自动项目归属与分身授权继承

本版在 1.1.8 的自动知识维护基础上，新增 **工作单元级项目归属**、**动态分身授权**和 **可选高速判断模型**。当前属于 PR #21 开发草案，尚未发布或完成真实资料验收。

## 功能

- AI 按每个可提取工作单元识别业务项目，而不是强制把整份文档/会话归为一个项目；保留明确的来源证据、归属判断和历史记录。
- 已知项目候选先校验工作单元自身的仓库/PR 等身份证据，再可通过可选判断模型（Jev SystemOne 或 Chat Completions）判定项目一致性；没有配置时默认使用主模型。
- 项目未能可靠判明时保持会话范围，不创建人工确认负担，不通过推断扩大跨来源共享权限。
- 个人版单独安全配置判断模型；企业版管理员在服务器上统一设置，员工无需供应商 Key。
- 数字分身可以一次授予整个项目、来源或通用知识范围；新增知识自动继承。保留旧版逐条知识勾选，允许显式拒绝规则。
- 本地问答、只读 MCP 和远程发布共用授权决策；每次检查来源 AI 权限与分享权限。AI 项目关联不会自行增加任何数字分身授权。

## 尚未交付和限制

持续重判历史不确定项目、完整跨会话连续操作追踪、浏览器事件采集、复杂混合文档的段落级权限分割以及真实授权资料的规模化误合并评测仍待完成。Jev 支持依赖具体供应商提供的 `/v1/systemone` API；未提供供应商 Key，因此目前仅执行模拟客户端和协议测试，不能声明真实付费调用已验收。
