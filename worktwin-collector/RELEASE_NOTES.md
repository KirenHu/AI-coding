# WorkTwin Collector 1.1.8 · 任务触发式浏览器行为采集（技术预览）

- 在「信息采集」新增浏览器来源：必须由本人手动开启，关闭后拒绝新的外部采集信号并撤销配对凭据。
- WorkTwin 内提供插件 ZIP 下载、安装指引、一次性配对码与连接状态；当前仅供 Chrome/Edge 开发者模式加载，尚未上架浏览器商店。
- 企业流程平台以 HMAC-SHA256 签发一次性 start/complete 信号，并在启动信号中提供经签名的任务状态查询路径。WorkTwin 主动向同源接口查询完成状态，连续无法确认状态时停止采集。插件只接受可信流程平台消息，无需用户维护动态目标网址白名单。
- 业务链接继续使用原生跳转，插件不会二次打开页面。采集只绑定来自该业务链接的指定标签页和首个文档，禁止因同名域名或同 URL 采集其他页面。
- 点击、变更、提交、分类后的页面反馈、导航和关闭事件写入独立 SQLite 表，按顺序生成简洁自然语言操作摘要与事件引用。独立的 AI 授权允许模型优化表述，不授权时使用本地规则；不保存表单输入值、页面正文、完整 DOM、视频、截图和查询参数。
- 首个网页发生文档跳转、SPA 导航或片段跳转时，记录目的地并立即停止采集，不跟随新的文档。采集停止与流程任务完成分别记录。支持短期重试和插件 Service Worker 会话状态恢复。

## 边界与验收

本版为**功能基础预览**，不是已经完成第三方业务平台联调的正式监控服务。流程平台的真实来源域名、扩展 ID 和签名配置需由管理员在部署阶段确定。目标网站首次浏览器权限可能需要用户确认，这是浏览器安全机制而非长期业务白名单。

当前提供本地自然语言操作概括与额外授权的模型概括，但**不提炼长期知识**，事件和摘要不会自动进入知识库和分身。真实 Chrome/Edge 的多标签、iframe、SPA、无痕窗口、插件休眠和不漏采边界尚需进一步验收。流程平台模拟签名和后端权限单元测试不能替代生产网页验收。

Mac/Windows 安装测试与 Apple Developer ID 签名、公证仍需分别判定；macOS 安装包未完成正式公证时标识为 unsigned 测试包。现有 1.1.7 的知识范围与权限规则继续生效。
