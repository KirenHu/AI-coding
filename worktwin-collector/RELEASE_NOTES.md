# WorkTwin Collector 1.1.5 · 知识范围与分身 MCP

- 修复长列表把设置入口挤出屏幕的问题，正文独立滚动，小窗口仍可直接点击设置。
- 知识记录项目、主题、适用范围、有效状态及来源归因。范围不明、低价值、仅报告完成或未解决冲突的内容停止参与回答。早期提炼但未核实的资料保留待核对，不自动变成有效知识。
- 同主题更新原笔记，保留编号；当前正文只保留最新有效结论，被替代正文仅存入变更历史和更新日志。Obsidian 仅作为部分设计思路的参考，未增加复刻或同步目标。
- 自动生效机制增加真实资料验收门槛，验收绑定模型和整理规则。无冲突新增、原文不变的纯补充可以自动生效；改变结论、项目不明、矛盾或模型重写仍需核对。当前有限真实样本不等于整份本地资料库验收，默认保持关闭。
- 数字分身可启用本地只读 MCP，直接沿用已保存知识授权，每次读取检查有效状态。支持项目列表、按范围检索、当前笔记与必要引用。完整来源日志默认关闭，必须单独授权，撤销立即生效。
- MCP 凭据可更新或关闭，数据库只存凭据摘要；更新后旧连接立即失效。连接只适用于本机，WorkTwin 需保持运行。
- 修复真实 DeepSeek 调用把“同意方案”误标为“成果验收”导致有效决策被整条过滤的问题；程序区分批准方案与验证成果，不将未验证完成声明降为已确认事实。

## 测试与边界

本轮使用用户授权的 Key 对实际产品讨论执行模型连接、知识提炼和结论替换判断，有限样本通过；自动生效未开启。模型 Key 不进入源码或发行文件。

MCP 使用官方 SDK 和官方客户端验证初始化、只读工具、知识隔离、日志单独授权、撤权、关闭连接及旧协议兼容。仍需打包客户端在 Codex、Claude Code 中的实际接入验收。完整工具执行日志、跨会话业务项目识别、浏览器采集与真实本地资料库的充分质量验收尚未完成。

升级前退出旧版，替换应用后重新打开。资料与模型配置保留；被暂停使用的早期提炼结果需要核对范围与价值后才能重新供 AI 使用。Mac 测试包仍未完成 Apple Developer ID 正式签名和公证。
