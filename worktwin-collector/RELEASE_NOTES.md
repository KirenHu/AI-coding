# WorkTwin Collector 1.1.6 · 编程工具操作记录（第一阶段）

- Codex 会话现在保留可见对话之外的工具调用名称、事件时间、结果返回以及可识别的进程退出码；Claude Code 会话支持 tool_use / tool_result 配对、失败标记及流式重复去重。
- 把操作事件作为独立证据类型插入时间线。工具事件不会混入用户确认或 AI 回复；Claude Code 使用 user 角色封装的 tool_result 也不能被误当作用户认可。
- 出于隐私和误归因风险，当前不采集工具参数、原始 stdout/stderr、工具结果正文与内部推理。这些内容不会被送给模型，也不会随完整日志 MCP 被额外暴露。
- 进程退出码 0 只能说明记录到了正常退出码，不能推断交付物正确或用户已验收。知识提炼的来源、归属、自动生效规则及分身权限仍按 1.1.5 执行。
- 增加 Codex / Claude Code 的解析回归及真实 SQLite 扫描入库测试，覆盖敏感输出排除、消息归因和执行成功/失败区分。

## 已知边界

尚未实现原始执行结果的隔离存储/按需核验、工作目录切换、复杂会话续接、跨会话业务项目自动归属和大规模真实本地资料质量验收。当前自动生效仍默认关闭。浏览器操作采集也未进入一期。

MCP 仍为本机只读服务，沿用数字分身现有知识授权，完整资料日志单独授权。此次采集到的操作摘要属于整理后的来源资料，不等于原始工具结果。正式的 Codex / Claude Code MCP 客户端接入验收仍待完成。

macOS 测试包尚未完成 Apple Developer ID 正式签名、公证和物理机器首次启动验收；按用户先推进功能的决定，该工作保持暂停。不要把测试包描述为经过 Apple 公证的正式安装包。

## 升级

退出旧版后替换安装包，再启动 WorkTwin。现有数据库、授权及模型配置保留。版本升级不会自动放行旧知识或开启自动生效。详见 README、一期边界和安装说明。
