# 数据、授权与分享

WorkTwin 将资料和知识保存在本机；你决定哪些内容可以交给模型、哪些知识可以被分身使用，以及是否远程分享。

## 几种授权分别控制什么

| 设置 | 控制范围 |
| --- | --- |
| 采集 | 是否继续读取该来源的新增与变化；暂停不会自动撤销已有知识 |
| AI 使用 | 是否允许该来源参与 AI 整理与分身回答 |
| 分身知识授权 | 某个分身可访问的项目、来源或指定文章 |
| 允许分身分享 | 来源是否可用于远程发布；仍需符合分身自身的知识授权 |
| MCP 完整来源日志授权 | 是否额外允许其他 AI 读取获准知识所引用的整份来源资料或会话 |

新增来源默认不会自动获得 AI 使用或分享许可。规则、技能和记忆文件作为有作用范围的参考资料保存，不自动执行其中指令。

## 哪些数据留在本机，哪些会发送出去

- **本机数据库**保存可检索的完整解析文本、知识、来源与版本。会话采集保存可见对话和工具动作摘要；工具参数、原始 stdout/stderr、工具结果正文与内部推理不进入知识分析或 MCP 日志。
- **配置的模型服务**接收获准使用的相关文本，用于知识整理和问答。本地保存不意味着模型调用离线。常见凭据文件会被排除，但目前没有企业 DLP 功能。
- **MCP 客户端**默认读取分身授权的当前有效知识与必要引用。完整日志需单独开启，可能包含同一来源中的其他讨论。
- **远程分享服务**接收分身获准发布的当前有效知识标题和正文，不上传原始文件或完整会话，偏好条目不参与发布。接收者问答使用服务端模型。

浏览器记录仅保存脱敏 DOM 事件，不采集表单输入值、页面全文或截图。个人记录可形成操作文章；平台专属任务事件不会自动进入个人知识库。

## 分享和撤销

远程访问链接相当于访问凭据，持有者可使用，也可能转发。接收者名称只是管理标签，不验证身份。链接最长有效期为 90 天，可以单独撤销。

本地修改、归档或撤销授权会触发同步，后台每 5 秒检查变化。**分享服务断开时，远端仍保留上次快照**，界面显示「尚未同步」；恢复连接后才能同步撤销。紧急撤销应直接在服务端完成。退出客户端不会停止已发布分身。

本地 MCP 直接使用当前授权，撤销知识、关闭 MCP、删除分身或更换连接凭据会使相应旧访问失效。

## 存储位置与备份

| 系统 | 默认数据库 |
| --- | --- |
| macOS | `~/Library/Application Support/WorkTwin Collector/worktwin.sqlite` |
| Windows | `%LOCALAPPDATA%\WorkTwin Collector\worktwin.sqlite` |
| Linux | `~/.local/share/worktwin/worktwin.sqlite` |

可通过 `WORKTWIN_DATA_DIR` 更改数据目录。macOS 密钥与企业 Token 使用系统钥匙串，Windows 使用凭据管理器，Linux 使用权限受限的本机加密文件。配置读取不会返回保存的密钥。

设置页提供 Markdown Wiki 导出和数据库备份。数据库备份不包含配置密钥，恢复时遵循随备份提供的说明。
