# 1.0 后续工作

1.0 已具备本地授权采集、审核式知识演化和养护、Markdown 链接与历史、企业统一模型费用控制，以及持久共享快照和到期/撤销链接。产品保持三个入口。

当前首先完成编程工具动作与执行结果的归属：已有 Codex/Claude Code 工具名称、返回状态和有限退出码线索，但还缺少能安全处理敏感内容的原始执行结果、工作目录变化、续接关系和文件产物核验。当前提供用户明确创建/关联项目身份的跨来源合并；其后仍需完善跨会话自动业务项目识别（必须有可靠证据，并让不确定归属进入核对，不能以同名或同目录推断），并以本人真实授权资料和当前模型评估提炼准确率、归因率、误合并率及自动更新准入。有限真实样本尚不足以自动开启更新。

组织部署需要接入已有 SSO、成员目录与资料 ACL，增加身份验证的协作者访问；链接标签目前仅供本人管理。按组织要求完成代码签名/公证、密钥安全存储、安装策略、备份恢复、长期后台与唤醒验收。

1.2.0 已开始任务触发式浏览器行为采集：可信工作流签名触发、首个页面事件及操作步骤、跳转即停止、WorkTwin 内插件引导和单独 AI 许可。下一步需在真实 Chrome/Edge 与流程平台完整联调，验证工作流按钮触发、文档身份关联、SPA/新标签页/断线/敏感字段边界，并将浏览器证据接入知识归属、引用与撤权闭环。后续仍可加入自动升级、托盘和反馈评测。个人行为风格建模继续作为内部能力，不增加终端用户的复杂一级管理入口。
