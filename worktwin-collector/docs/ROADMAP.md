# 产品路线图

## 已实现：v0.5 本地试点与可审核知识更新

1. 采集授权入口：文件夹、Codex、Claude Code；增量扫描、暂停与撤销。
2. 知识库入口：按项目分类、检索、文档详情、来源证据、人工编辑、历史版本。
3. 数字分身入口：创建、编辑、删除，勾选授权知识，企业模型配置就绪后本地试问。
4. 后台采集与整理解耦：本地持久任务队列、企业 BYOK 网关、失败重试、来源失效隔离。
5. 可审核的知识演化：新增 / 补充 / 替换 / 冲突提案、旧版历史、关联证据与撤权复核。
6. 有界企业模型调用重试、Python wheel 和 Chromium UI / HTTP 自动化验收。

## P1：知识质量和实机体验

- Mac/Windows 原生托盘、后台启动、静默更新、代码签名/公证、企业安装包。
- 真实 Codex / Claude 历史资料中抽样评测：知识识别精度、来源可验证率、误归因率、更新速度。
- 用真实项目资料评估跨资料主题关联和冲突提案的精确率与误触发率，优化提案排序与处理体验。
- 个人知识中隐私标记与组织资料标签，敏感信息检测，对企业模型侧的数据流进行审计。
- 企业 BYOK 网关预算限额、负载控制、错误告警与分级重试策略。

## P2：组织级分身分发

- 企业 SSO/成员目录、角色权限、工作内容归属；既服从员工授权，也受原始企业资料访问控制约束。
- 将允许分享的知识选择性同步到企业服务器，并建设离线可用、撤权、失效与到期策略。
- 独立分身的协作者授权、分享链接、操作记录与审计；不同数字分身共享知识资产但各自有独立授权视图。
- 员工休假/离职交接流程，不把个人敏感资料自动转移为企业资产。

## P3：持续学习与迭代闭环

- 通过用户工作反馈改善知识合并、重要程度排序、准确率；为知识更新与分身回答建立评测集。
- 员工个人思维逻辑与表达风格建模放在内部，不成为终端用户默认的复杂设置项。
- 浏览器扩展与其他获许可应用事件采集；屏幕感知仅在有明确隐私价值和授权机制后考虑。
