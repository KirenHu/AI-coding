# WorkTwin 一期边界

一期服务个人使用和小范围企业试点，完成「配置模型 → 授权资料 → AI 提炼 → 人工确认 → 分身授权 → 问答与引用」闭环。

| 使用者 | 模型配置 | 费用与凭据 |
|---|---|---|
| 个人 | 设置中填写兼容服务的地址、模型和 API Key；真实测试成功后保存 | 使用个人模型账户 |
| 企业员工 | 填写企业服务地址与员工 Token；可测试实际调用 | 使用企业分配的模型，不获得供应商 Key |
| 企业管理员 | 同一设置界面按权限显示模型、调用限额、员工 Token 管理 | 供应商 Key 只保存在服务端 |

三个主要入口保持为信息采集、我的知识库、我的数字分身。设置作为辅助入口，在小窗口中仍可见。个人与企业共用客户端；后台依据管理员身份校验权限。原始资料保存在本人电脑；共享快照和接收者问答由持续运行的服务器负责。

## 一期必须能够验收

- 模型设置可获取模型列表或手动填写、真实测试、保存、启动后重新读取。员工不能读取或修改企业供应商密钥。失败不显示成功，不覆盖可用配置。
- 工作目录、Codex 与 Claude Code 的资料由本人授权；采集、AI 整理、分享分别控制。处理状态区分排队、运行、失败，并可重试。
- AI 知识先生成草稿，人工核对后确认。草稿、待核对、已确认、归档可以筛选。归档可恢复为待确认；个人偏好可见、可编辑、可删除，不分配给分身。
- 编辑关闭、Escape、切换页面和退出前保护未保存内容。分身名称、用途与知识授权一起保存，失败保留输入。
- 分身只使用已确认、来源有效且全部来源允许 AI 的知识。发布还要求全部来源允许分享。配置页显示可问答、可发布数量及排除原因。
- 问答保留本次打开应用期间的聊天记录；Enter 发送，引用可以打开。可试问本地已保存授权或服务端实际发布版本，两者范围明确。
- 分享链接有有效期、可以撤销。刷新同一标签页继续访问；权限失效后不能继续读取知识或问答。本人电脑关闭后，远程服务仍可回答。
- 设置提供 Markdown Wiki 和数据库备份；备份不包含配置密钥，并附恢复步骤。

## 后续阶段

组织 SSO、原有文档 ACL 自动联动、企业 DLP、多租户运营后台、货币账单预算、自动升级、扫描件 OCR、跨设备个人同步、批量确认和手工项目分组不在本次一期交付内。多人生产部署与知识效果需要组织自己的资料和实际模型验收。

Apple Developer ID 签名与公证取决于开发者账户审批。本次测试包不代表这些手续已经完成。自动测试使用合成资料及模拟模型，不能据此宣称真实知识准确率。
