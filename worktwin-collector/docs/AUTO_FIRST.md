# WorkTwin 知识维护：自动化优先

产品目标是 AI 在授权范围内自动整理、更新和纠错知识，而不是建立逐条人工审核队列。来源授权、分身授权和完整日志授权仍由用户控制。

- 不确定项目时，将知识限定在当前来源或会话，不触发人工确认；不能凭目录名直接跨项目合并。
- 有明确来源证据的新增、补充及更新，优先自动生效，保留变更历史和撤回入口。
- 来源已变更或撤销授权时，自动刷新或撤销受影响知识，不让用户逐条清理。
- 高风险跨来源冲突、用户明确修正的结论遭覆盖、对外分享权限扩大时才要求确认。
- 区分 AI 推断、源材料陈述与人工确认；自动生效不应被伪装成“用户已确认”。
- 未解决的中低风险歧义保留来源隔离并由后台继续分析，而不是进入待办审核队列。

度量：每百次知识变更需要多少次人工处理、自动更新覆盖率、误合并率、错误传播率与撤回率。
